## About Verokod

**Verokod** is an independent software studio building small, focused utilities for Windows.

Most software today asks for an account before it does anything, phones home with usage data, and buries one useful feature under ten nobody asked for. We build the opposite: tools that work offline-first, respect your machine, and finish the job in as few clicks as possible.

Every Verokod tool is:

- **Private by design** — your data stays on your PC. Nothing is uploaded, tracked, or sold. Ever.
- **Honest** — no fake "free" traps, no dark patterns, no features held hostage.
- **Lightweight** — quick to install, quick to open, and it leaves your system the way it found it.
- **Free to use** — supported voluntarily by the people who find the tools useful.

## Our Tools

### All Browser Cleaner

**Clean browsing data from every installed browser — all at once, in one click.**

Windows PCs collect history, cookies, cache and site data across every browser installed on them. Cleaning that up normally means opening each browser one by one and digging through its settings. All Browser Cleaner does it all in a single pass.

**What it does:**

- Detects **every installed browser automatically** — Chrome, Edge, Brave, Firefox, Vivaldi, DuckDuckGo and more
- Cleans history, downloads list, cookies, cache, site storage, site settings and autofill data
- **Per-browser selection** — a browser you don't tick is never closed and never touched
- **Protect lock** — mark your main browser as Protected and it can never be cleaned by accident
- **Bookmarks and extensions are never removed**
- Optional deep items (saved passwords, extension storage) stay **off by default** and ask for extra confirmation
- A clear activity log shows **what was cleaned and how much space came back** — nothing else
